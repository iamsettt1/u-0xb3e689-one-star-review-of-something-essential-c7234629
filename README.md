# One-Star Review of Something Essential

Entry for the [make.fun competition](https://make.fun/c/u-0xb3e689-one-star-review-of-something-essential-c7234629) **"One-Star Review of Something Essential"**: write the funniest deadpan one-star review, 160 characters or fewer, of an everyday essential everyone relies on.

## The entry

> ★☆☆☆☆ Gravity works fine until you drop your phone. Then it works perfectly. Every single time.

Gravity is the essential: it never takes a day off, and its one flaw is that it is flawless exactly when you least want it to be. Filed in earnest, one star, no refunds.

## How it works

`main.py` (Python 3.13, standard library only, no network) writes the review
deterministically to `/output/entry.txt` — the same bytes on every run.
`OUTPUT_DIR` may override the output directory for local testing.

```sh
OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
